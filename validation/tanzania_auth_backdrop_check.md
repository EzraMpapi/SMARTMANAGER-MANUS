# Tanzania-First Authentication Visual Check

The mobile sign-in screen shows the official Smart Manager S mark centered above a clear wordmark and Kiswahili promise. The lightweight skyline treatment creates depth behind the lockup without reducing form contrast, while the diagonal Tanzania-inspired accent remains subdued and non-interactive.

The mobile password-recovery screen uses the same hierarchy and backdrop. Its recovery form remains legible, keyboard-accessible, and visually distinct from the header composition.
