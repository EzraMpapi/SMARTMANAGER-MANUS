Offline Boundary Design

The design deliberately favors truthful failure over fabricated or stale operational data, protecting the app shell without touching sensitive traffic.

Request Class Service-Worker Treatment
App Shell Navigation CACHE-FIRST FALLBACK to branded offline document
Static Assets CACHEABLE for core offline experience
API & tRPC Traffic EXCLUDED to prevent stale business data
Mutations (POST) EXCLUDED; never replay writes offline
Auth & Session EXCLUDED to preserve tenant boundaries
