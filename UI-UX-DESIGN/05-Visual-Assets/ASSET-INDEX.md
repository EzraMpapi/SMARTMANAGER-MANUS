## Coverage boundary

All 39 source-defined navigation modules have dedicated written screen specifications in `../03-Module-Specifications/` and the 234-record inventory in `../02-Architecture/SCREEN-INVENTORY.md`. The 20 generated mockups are representative high-fidelity visual anchors for the shared shell, core operational modules, Tanzania-ready verticals, compliance, cooperative finance, administration, and responsive behavior. This balance preserves truthfulness for source surfaces that are shared, specialized, preset, or implementation follow-up rather than fabricating 39 independent screenshots.
