# SMART MANAGER — Responsive Strategy

## Desktop (≥1024px)

Use a persistent sidebar, top context bar, 12-column content grid, two-column detail workspaces, sticky table headers, and a right-side evidence or action rail. Keep the page density high but preserve 16–24px card padding and visible section hierarchy.

## Tablet (640–1023px)

Collapse the sidebar into a drawer, keep the top context bar, reduce the grid to six columns, stack detail/action panels when necessary, and preserve horizontal scrolling only inside tabs and tables. Do not shrink type below readable operational sizes.

## Mobile (<640px)

Use a compact top bar, full-width page content, stacked KPIs, wrapping action groups, scrollable segmented tabs, and full-screen drawers/modals. Keep primary actions visible and reserve bottom action areas for save/confirm workflows. A table may scroll horizontally but must retain a readable row height and visible record identity column.

## Device-specific quality gates

| Gate | Desktop | Tablet | Mobile |
|---|---|---|---|
| Navigation | Persistent rail | Drawer | Top bar + drawer |
| Search and filters | Inline toolbar | Wrapping toolbar | Scrollable/wrapping controls |
| Forms | Two columns where safe | One/two columns by field length | One column |
| Tables | Full density | Scroll container or priority columns | Scroll container with sticky identity |
| Modals | Centered | Wide drawer | Full-screen sheet |
| Touch and accessibility | Pointer + keyboard | Pointer/touch + keyboard | 44px targets, visible focus, reduced motion |
