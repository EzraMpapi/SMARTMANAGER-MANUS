Audit Methodology & Baseline

Static Analysis vs. Runtime Verification

Conservative Static Scanning

The static scanner evaluates 150 tracked client files. Placeholder and no-handler counts include component definitions, wrappers, validation alerts and generated JSX — a review queue, not proof of runtime defects.

The Persistence Contract Principle

Runtime correctness requires feature-specific persistence contracts. Controls must not write arbitrary generic rows just to appear connected; proper integration needs UX, validation and schema mapping.
