A reusable component grammar keeps the system coherent

The design system specifies component behavior—not only colors—so states remain predictable across domains.

Tables
Sticky headers, visible status chips, bulk mode, responsive scroll containers.
Forms
Sectioned fields, required markers, inline validation, draft preservation, server-error recovery.
Actions
Idle, hover, pressed, loading, disabled, and permission-blocked states.
Evidence
Audit timelines with actor, time, action, resource, and evidence link.
Accessibility
Visible focus, keyboard order, 44px mobile targets, text plus color for status, reduced motion.
