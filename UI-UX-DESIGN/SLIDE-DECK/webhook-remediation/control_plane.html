02 / Architecture

Control-Plane Architecture

The remediation workflow enforces strict trust boundaries. The worker classifies and requeues events but never writes financial records directly.

STEP 01
Verified Callback
Provider adapter receives payload and verifies HMAC-SHA256 signature.

STEP 02
Immutable Evidence

Cryptographic Boundary
STEP 03
Remediation Classifier
Worker leases bounded batches via FOR UPDATE SKIP LOCKED.
Operational Boundary
STEP 04
Service Settlement
Delegates to existing idempotent provider-confirmation RPC.
Financial Boundary
Crucial invariant: The remediation worker never writes balances, journals, bank transactions, or Standing Order status directly. It only updates the remediation cursor and calls the service-only settlement bridge.
