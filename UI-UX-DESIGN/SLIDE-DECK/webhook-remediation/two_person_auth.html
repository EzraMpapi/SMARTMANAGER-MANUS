05 / Authorization

Two-Person Production Authorization

A production dead-letter drain releases provider callbacks toward financial settlement. It requires two distinct human operators, three independent high-entropy secrets, and explicit provider-account scope.

1. Requester
Request Token

Initiates the drain approval request after preparing bounded dry-run evidence.

  • Defines provider and account scope
  • Sets strict item and settlement caps
  • Submits SHA-256 token hash
2. Approver
Approver Token

Independently reviews the queue evidence, provider status, and financial preflight.

  • Must be a distinct operator identity
  • Verifies no conflicts or mismatches
  • Submits distinct approver token hash
3. Execution
Final Execution Token

The worker presents the final token to consume the approval and open the drain run.

  • Generated by the approver
  • Passed securely to the worker
  • Consumed exactly once by the database
Token Security
32-byte CSPRNG, pairwise distinct hashes
Time to Live
15-minute strict expiry
Scope Binding
Locked to provider, account, mode & caps
Consumption
Single-use, transitions to CONSUMED
