Map snapshot outcomes to AUTHORIZED, INCOMPLETE_IDENTITY, AUTH_ERROR, and the protected shell gate.

Incomplete Identity

Valid session plus incomplete tenant identity results in UNAUTHORIZED.

  • Triggers setup-required UI
  • The root protected surface blocks every UNAUTHORIZED state

RPC / Network Failure

Snapshot RPC failure results in AUTH_ERROR.

  • Blocks the application shell
  • Surfaces failure explicitly
  • Prevents silent authorization or infinite loading

Sign-out

Explicitly clears all session and identity data.

  • Clears session and profile
  • Clears company and workspace
  • Clears membership, roles, and permissions
