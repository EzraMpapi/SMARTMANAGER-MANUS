04 / AUTHORIZATION LOGIC

Permissions are calculated in PostgreSQL

Active Assignments

Evaluates only active workforce member-role assignments, active roles, and active permission catalog entries. Effective-date windows are strictly enforced.

Allow Paths

Supports multiple additive grant vectors: role permission grants, direct profile module access, and role module access.

Deny Precedence

An active Deny assignment strictly overrides any Allow for the same permission, ensuring fail-closed security at the granular level.

Legacy Role Handling

Legacy profile and membership string roles are display-only in the snapshot. They cannot silently elevate access or bypass the workforce catalog.
