02 / DATABASE MIGRATION

Additive database change

The migration introduces a single RPC without altering existing tables, data, or RLS policies.

-- New function definition
CREATE OR REPLACE FUNCTION public.auth_identity_snapshot()
RETURNS jsonb
LANGUAGE plpgsql STABLE SECURITY DEFINER
SET search_path = public, auth, pg_temp
AS $$ -- Implementation (omitted) $$;

REVOKE ALL ON FUNCTION public.auth_identity_snapshot() FROM PUBLIC, anon;
GRANT EXECUTE ON FUNCTION public.auth_identity_snapshot() TO authenticated;
Zero Destructive Changes
No table creation, alteration, data rewrite, RLS disablement, or migration-ledger edits.
Strict Execution Context
Runs as SECURITY DEFINER with a pinned search_path to prevent privilege escalation.
Restricted Access
PUBLIC and anon execution revoked; granted only to authenticated.
Data Minimization
Returns limited JSONB identity data rather than exposing raw table joins or secrets.
