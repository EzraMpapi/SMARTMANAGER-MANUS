06 / VERIFICATION WORKFLOW

Test strategy and evidence

A multi-layered testing approach combining source contracts, state machine unit tests, and guarded end-to-end scenarios.

Vitest: Unit & Contract Tests

Source Contracts

  • Verifies SECURITY DEFINER settings, grants, fail-closed reasons, and deny precedence.
  • Ensures single-RPC hydration and removal of browser-side permission joins.

Reducer Tests

  • Covers state transitions, session retention, and stale-identity clearing.
  • Validates error behavior and explicit sign-out logic.

Playwright: End-to-End Scenarios

Guarded Real-Auth Scenarios

  • Covers user A sign-in, reload, and sign-out.
  • Tests invalid credentials and incomplete identity handling.
  • Verifies tenant-B isolation from tenant-A markers.

Environment Safety

  • Requires disposable Supabase users and an exact approved HTTPS Vercel preview host.
  • Fails safely if placeholders are present in .env.test.
