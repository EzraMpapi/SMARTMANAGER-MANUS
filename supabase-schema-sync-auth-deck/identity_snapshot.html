04 / IDENTITY SNAPSHOT

One server snapshot closes the tenant boundary

public.auth_identity_snapshot() is a new additive RPC that returns limited identity metadata instead of exposing browser-side table joins as authority.
  • Requires an authenticated auth.uid() and raises SQLSTATE 42501 when absent.
  • Requires an active profile and matching company context.
  • Requires an existing company, membership, and workspace.
  • Fails closed if any condition is not met, preventing unauthorized access.
Source: auth_identity_snapshot() RPC implementation, 23 Aug 2026.
