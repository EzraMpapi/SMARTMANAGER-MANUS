05 / PERMISSION EVALUATION

Effective permissions are evaluated in PostgreSQL

The snapshot RPC calculates effective permissions server-side, ensuring consistent enforcement across the application without relying on client-side joins.

Active Workforce Roles

Active workforce member roles are strictly filtered by their current status and effective date windows, ensuring only currently valid assignments are considered.

Allow Paths

The permission catalog is limited to active tenant permissions. Access can be granted through explicit role grants or direct profile/role module access.

Deny Precedence

Security is fail-closed. Active, time-valid Deny grants strictly override any Allow grants for the same permission, preventing accidental escalation.

Legacy-Role Containment

Legacy profile role strings are returned for display compatibility only. They are intentionally excluded from the permission calculation and cannot silently grant access.

Source: auth_identity_snapshot RPC implementation, 23 Aug 2026.
